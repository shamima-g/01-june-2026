**4. File detail with validation errors and retry validation**

An Approver sees the same error list but no Retry button. From a healthy file you can drill into its transactions.

**5. Cancel a file (guarded against approved transactions)**
As an Importer, on a file's detail you can Cancel it. A confirmation dialog names the file and defaults focus to Cancel before anything is removed. Once confirmed, the file is deactivated and its transactions disappear from the Approver's working list. If any transaction in the file has already been Approved, Cancel is blocked and you see an explanatory banner instead. Approvers never see the Cancel action.
